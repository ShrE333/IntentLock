# V11.5.1 — Source and Deployment Verification

**Type:** additive instrumentation and read-only release audit. Does not replace local V11.5 code.

## Changes

- `GET /api/build-info`: uncached, public, minimal deployment identity (`service`, `release`, `gitCommit`, `gitBranch`, `deploymentEnvironment`). Exposes no secrets or account data.
- `tools/release-v1151/audit.mjs`: verifies source inventory, Git tree cleanliness, obvious staged sensitive paths, CI/browser/typecheck presence, optional live Vercel SHA and Worker `/health` (GET only). WAHA does not gate the checks.
- `tools/release-v1151/run-validation.ps1`: invokes repository's unit tests, strict typechecks, Next production build, Wrangler dry-run; optional Playwright and isolated PostgreSQL migration check.
- `tools/release-v1151/APPLY.ps1`: safe no-overwrite installer.

## Exclusions

No production deployment, migrations, payment/checkout creation, capture, refunds, PayPal credential checks, WAHA startup or enterprise authentication changes.

## Rollout gates

1. Confirm all V11.4.3–V11.5 source files are committed in an intended integration branch; compare the resulting SHA with the source CI tested.
2. Validate Worker + frontend with no financial mutations and WAHA off; document Playwright screenshots separately for visual comparison.
3. Verify Vercel production Git branch, `apps/web` root directory and `NEXT_PUBLIC_INTENTLOCK_API_URL` build-time environment.
4. Push integration branch and test an isolated Vercel preview; confirm `/api/build-info` reports the intended commit.
5. Only after reviewing schema/grant/merchant permissions, promote to production. Do not turn on financial execution solely because the frontend deploys.
6. After deployment, rerun read-only site/Worker checks and manually verify mobile/desktop routes and the no-payment judge demo.

## Verified versus not verified by this package

- Verified: the scripts and route can be syntax-tested locally and the package is non-destructive by construction.
- Not verified: the user's uncommitted D:\IntentLock files, Vercel dashboard deployment and environment settings, production database status, PayPal sandbox transactions, WAHA service.
